# Image Type Converter

This project is meant to test the capability of using Pillow to convert a folder of `.jpg` images to `.png`.

## How to use?

Using Python directly:

``` bash
python3 ./src/type_converter/main.py jpg_folder new_png_folder
```

Using uv package manager:

``` bash
uv run --active ./src/type_converter/main.py jpg_folder new_png_folder
```
